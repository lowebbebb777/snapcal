# SnapCal for Windows — 文字をコピーするだけで予定登録

Windows 10/11の **SnapCal.exe 1つ** に統合しました。画像OCR・Tesseract・Pythonのインストールは不要です。タスクトレイで静かに動作し、`Ctrl+C` などでコピーした文章から予定候補を読み取ります。

- **確実な予定が1件：** 自動でGoogleカレンダーに登録。コピー以外の操作は不要。
- **候補が2件以上：** SnapCalの候補選択画面が出るので1件だけクリック。
- **日時はあるが予定の意図が曖昧：** 勝手に登録せず、確認画面で1回クリックした場合だけ登録。
- **自然文：** 「来週火曜14時から打ち合わせ」「明日午後3時から面談」も登録候補として解析。
- **予定詳細：** 「場所・会場」「終了時刻」「メモ・備考・内容・詳細」などの明示された項目を読み取り、Googleカレンダーの対応する欄に登録。
- **メモや曖昧な詳細：** Googleへ送る前に、読み取った内容を確認する画面を表示。
- **日時・タイトルが不明：** 何も登録しない（誤登録を防止）。
- **同じ予定が登録済み：** Googleカレンダーを照会して重複登録を避ける。
- **画面上の邪魔なバブル：** なし。Windowsの通知領域アイコンだけ。
- **画像：** Windows版では扱わない。通常の文章コピーに集中。
- **Android：** 同じSnapCal製品のAndroid APKはスクショ自動登録に対応。

## Windows版の入手・起動

1. リポジトリのGitHub Actionsで **Build SnapCal Windows portable EXE** の成功した実行結果を開く。
2. Artifacts の `SnapCal-Windows-EXE` をダウンロードしてZIPを展開する。
3. `SnapCal.exe` を起動。Windowsに別の常駐アプリをインストールする必要はありません。
4. 初回のみGoogle認証を設定。下記参照。設定完了後は「予定文章をコピー」するだけです。

## 初回のみ必要なGoogle認証

Googleカレンダーへ**操作ゼロで書き込む**には、Google Calendar APIへのOAuth認証が必須です。SnapCalはユーザーのGoogleパスワードを扱わず、ブラウザでGoogleから許可を得ます。

現時点の試作版では次の1回限りの設定が必要です。

1. Google Cloud Consoleでプロジェクトを作成し、**Google Calendar API** を有効化。
2. OAuth同意画面（Google Auth Platform）を設定し、**デスクトップアプリ** 用OAuthクライアントを作成。アプリがテスト状態の場合は自分のGoogleアカウントをテストユーザーへ追加。
3. ダウンロードした `credentials.json` をSnapCal起動時のファイル選択画面で指定する（手動でコピー先を探す必要はありません）。
4. 次に予定をコピーするとブラウザが開くので、Googleカレンダーへのアクセスを許可する。

設定は `%LOCALAPPDATA%\SnapCal\` に保存。OAuthのJSON・トークンを他人に渡したりGitへコミットしたりしないでください。Google認証を設定しない間は自動登録されません。

**テストモードの認証期限：** Googleの「外部 / テスト中」OAuthクライアントは、Google Calendarスコープの更新トークンが原則7日で期限切れになります。これはGoogle側の制限で、SnapCalでは延長できません。期限切れ時はSnapCalがGoogleのブラウザ認証を再開します。必要なら通知領域のSnapCalアイコン → **「Google認証を更新」** から再認証できます。通常、OAuth JSONの再ダウンロードは不要です。一般公開・販売時はGoogleの適切な公開設定と必要な審査を別途検討します。

## 文章例

```text
青空クリニック 11月2日（月）16:50
```

```text
会議
11月4日（水）
14:30
```

```text
青空クリニック
11月2日（月）16:50
定例ミーティング
11月3日（火）18:30
```

最初の2例は自動登録、最後は候補選択。終了時刻がない場合は1時間後に設定します。

**自然文の例**（1件だけで予定の意図が明確な場合）：

```text
来週火曜14時から打ち合わせ
```

**誤登録防止の例：** 「会議は中止」「例えば会議が…」は登録しません。日時のあるニュース、資料、長いメールや意図が不明な文章は、確認が必要な場合だけ選択画面を出します。

## 予定の詳細を取り込む

同じアプリ内で「タイトル・開始・終了・場所・メモ」を扱えます。場所やメモは**ラベルで明示された場合だけ**抽出します。

```text
定例会議 2026/11/12 14:10
終了時刻: 16:45
場所: 福岡支店3階
メモ: 資料を持参
```

この文章をコピーすると、詳細付きの予定1件を候補にし、**メモをGoogleへ送る前に確認画面**が開きます。「登録しない」を選ぶと何も送信しません。終了時刻は `14:10〜16:45` のような時刻範囲でも指定できます。

場所だけが明確な短い予定は、従来どおり自動登録できます。曖昧な終了時刻・矛盾する場所などは勝手に確定しません。複数の予定では、直後にあるラベル付き詳細だけを該当予定に結びつけます。すでに同じ時刻・タイトルで登録済みの予定は、詳細情報が違っても**無断更新しません**。

Google認証JSON・トークンの再設定は通常不要です。既存のSnapCalをトレイから終了し、新しい`SnapCal.exe`を起動してください。

## プライバシーと制限

- コピー内容はメモリ内だけで判定。元の文章・個人情報・コピー履歴をファイル保存しません。
- 明確な予定で必要な場合のみ、タイトル・日時・明示した場所・明示したメモがGoogle Calendar APIに送られます。メモは登録前に確認します。
- Googleカレンダーへの登録・重複確認にはネットワーク接続が必要です。
- 言語理解は現時点では決定的ルールに限定。来週の曜日・今日・明日・明後日の表現に対応しますが、AIによる汎用文脈推定ではありません。
- 旧版のWindows実機で、コピーからGoogleカレンダーへの自動登録はユーザー確認済み。今回追加した**詳細抽出と確認画面は実機未検証**。GitHub Actionsでは構文・単体テスト・実行ファイル生成を確認します。
- exeのコード署名は未実施。Windows SmartScreenの注意表示が出る場合があります。
- 以前の `windows_companion` 画像OCR試作を実行している場合は終了し、**SnapCal.exeだけ**を起動してください。

## 実機回帰テスト（最新版）

1. SnapCal.exeが起動している状態で「テスト会議 2026/11/5 16:50」をコピー → 自動登録（既に登録済みなら重複しない）。
2. 「来週火曜14時から打ち合わせ」をコピー → 1件だけ自動登録。今週ではなく **来週の火曜** になっているか確認。
3. 「会議を中止 2026/11/5 16:50」をコピー → 登録されない。
4. 「新着ニュース 2026/11/5 16:50」をコピー → 登録前に確認画面。登録せず閉じることが可能。
5. 「青空クリニック\\n11月2日16:50\\n定例会議\\n11月3日17:30」を**改行付き**でコピー → 候補2件。2件目を選ぶと2件目だけを登録。
6. SnapCalの通知領域アイコン → 「Google認証を更新」 → Googleの認証画面が開くか確認。

※テスト予定はGoogleカレンダーから削除できます。実機確認後でなければ新機能を受入済みにしません。
